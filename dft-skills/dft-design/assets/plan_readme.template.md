## 参数与首次审核

| 参数 | 当前值 / 单位 | 来源 | 精度证据 |
|---|---|---|---|

`design_mode: task` 使用实际给定参数；`user_specified` 表示用户指定、精度未验证，
不等于 `validated`。研究模式才展开假设、对照和收敛研究。
先初始化全部草稿目录与可确定输入，再完成一次参数审核并绑定真实审批事件。
草稿不可提交；首次审核后的授权任务不重复审批。磁盘上的用户参数优先。

## 状态、停止条件与下一步

记录当前状态、预期完成条件、有限重试边界、阻塞和下一步。
workflow.json 是唯一活跃叶账本；调度完成、产物完整、科学接受分别记录。
资源模板由 dft-submit 管理，已有配置复用项目缓存，不重复资源审查。
技术故障留存被替换证据后原地修复；计算完成但结果不符预期时保留源结果，
通过 `rerun_NNN` 和 `derived_from` 建立新候选。
