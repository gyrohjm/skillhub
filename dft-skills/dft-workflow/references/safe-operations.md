# Safe workflow operations

Do not run production engines on login nodes. Cluster/resource/launcher conventions
come from dft-submit, not a parallel checklist here.

A draft cannot submit. The real one-time parameter approval covers only the agreed
execution scope. Ordinary user edits are adopted through reconciliation; do not undo
them based on old hashes. Unknown meaning goes to an Agent; major conflicts return
to the user. Do not alter physical parameters as a performance shortcut.

Preserve immutable running snapshots, existing Selective Dynamics and the approved
starting structure. Technical retries preserve replaced evidence in attempts before
same-leaf repair. Completed unexpected results are retained and branched, not overwritten.
Validate dependency identity and convergence before handing a relax structure to SCF.
Do not introduce shared writable restart data between concurrent calculations.

Cancellation, relocation, export and deletion need explicit target scope.
Never clean broad paths/globs or publish licensed pseudopotential content.
Submission uncertainty must be resolved from receipts and scheduler evidence before retry.
