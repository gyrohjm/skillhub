# Wannier 拟合闭环

## 1. 定义验收目标

先明确模型用途：目标能区的能带插值、费米面、轨道紧束缚解释、拓扑相关
量或 EPW 电子模型。局域化程度只是其中一个指标。记录能量单位和参考零点，
尤其区分绝对能量与 `E-EF`；不能把两种零点下的能窗直接比较。

阈值来自当前课题目标及 DFT 参考精度，不固定宣称所有体系都适用某个 meV
数值。若用户尚未确定阈值，可给建议及其理由，不能据此自封最终验收通过。

## 2. 从证据到约束

记录实际软件版本，查询对应版本文档/源码；不把最新版默认值套到未知版本。
数值、版本或来源不明确时保持 UNKNOWN。

| 检查 | 必要证据 | 处理 |
|---|---|---|
| 子空间维度 | `num_wann`、排除能带后的有效带数、原始带号映射 | 维度不自洽先修约束，不增加迭代数 |
| 能窗容量 | 每个源 k 点的本征值和实际内/外能窗 | 解纠缠时检查每 k 点 `n_frozen <= num_wann <= n_outer`；数据不全不可宣布通过 |
| 投影与自旋 | 展开后的投影、spinors/DFT 自旋模式、轨道证据 | 不按 `proj(i)` 的行数推断轨道数，不把空间轨道数当旋量维度 |
| 输入网格 | 实际 k 点、顺序、权重/约定、矩阵维度 | 网格尺寸相同不证明实际点集与顺序一致 |
| EPW 有效设置 | 原生参数、wdata、生成 win、版本 | 重复来源冲突不得静默选旧计划或某一来源 |
| 复用有效性 | 输入/赝势/结构/自旋/带号/网格与输出来源 | 文件存在、非空都不足以证明与当前模型兼容 |

原始带号、排除后的带号和 Wannier 插值带号必须显式区分。不要直接用
`num_bands - 排除项数量` 代替完整映射验证，尤其警惕已排除输入和索引区间。

## 3. 选择最小实验

| 观测 | 优先检查 | 候选实验 |
|---|---|---|
| 冻结态数超维度或外窗态不足 | 能量零点、带号映射、每 k 点计数 | 修正能窗或在授权范围内调整模型维度 |
| 杂化区误差集中 | 目标轨道权重、投影子空间覆盖 | 有证据地修改投影或基组；不单靠增加 `num_iter` |
| 解纠缠迭代震荡 | 真实逐步 Omega_I 序列、窗口/投影合法性 | 一次试一个解纠缠控制族，验证震荡和能带误差 |
| 子空间可信但局域化不稳 | spread 序列、最后一次完整中心/展宽块 | 检查局域化步长/策略，勿把不同迭代的中心拼成同一组 |
| spread 小但能带差 | 独立 k 点对照、丢失带/杂化特征 | 回查子空间、能窗和投影，而不是认定已收敛即合格 |
| 重启后结果异常 | 模型哈希和重启谱系 | 标记不兼容，准备新数据；不直接删除旧重启文件 |

这些是诊断顺序，不是无条件参数配方。没有轨道分析时不臆造“缺少某轨道”。
同一失败连续重复、没有改善或达到已约定次数/成本上限时结束迭代并报告。

## 4. 验证层次

### 数值层

区分正常终止、解纠缠收敛、局域化收敛、迭代到顶和警告。解析器应区分
最后一次完整输出块及历史记录；残缺输出不能补成已收敛。

### 电子模型层

- 先核对 DFT/Wannier 使用相同结构、物理设置、能量参考、k 坐标与可比较
  的能带子空间。不以每个 k 点任意能量平移来“优化”误差。
- 使用有代表性的高对称路径图定位问题，并用独立均匀/随机 k 点及目标
  费米面附近点检验泛化；拟合所用粗网格上的一致性不是独立验证。
- 报告目标能区 MAE/RMSE、最大误差、带边/能隙/费米交叉等适用特征。
  对未完整采样的能区明确标记覆盖不足。
- 简单带序匹配不可靠时，使用已有轨道/波函数重叠证据或明确的子空间匹配；
  交叉/简并处不能把带序错配当插值误差。能量集合相近也不证明轨道角色正确。
- 外窗或模型维度修改后保持原目标评价集，不能通过删掉拟合差的带降低误差。

### 目标物理层

EPW：确认所需费米能区落在实际验证过的范围内。`fsthick` 与 Wannier 冻结
窗不是同一个参数，具体窗口约定按所用 EPW 版本核验。费米面/能带验证通过
只支持电子模型的就绪判断；EPC 矩阵元及后续物性仍需要独立验证。

拓扑或轨道解释：能量误差小不证明波函数、对称性、Berry 相关量正确；缺少
相应验证时只报告能量插值层面的结论。

## 5. 原型向可执行闭环演进的顺序

当前已实现普通 `.win/.wout/.eig` 检查及显式对齐 JSON 能带比较，见
[CLI 文档](cli.md)。以下是真实计算闭环仍需逐步完善的路线，不是已完成声明。

1. 加固 `.win/.wout/.eig` 提取：真实版本样例、最后输出块、三值状态、
   带号映射与每 k 点能窗计数。先让错误输入不能假通过。
2. 连接 DFT 对照数据：优先 QE/EPW，保留通用 Wannier90 接口；VASP 需要
   单独适配及测试，不伪装为已支持。
3. 实现匹配明确的独立能带验证、误差图及候选比较。
4. 在测试覆盖后连接现有 `dft-workflow` 的有界执行与 lineage；不另造提交器。
5. 若目标需要，再扩展 EPC 矩阵元/物性验证；不能提前使用 EPW_READY 作笼统成功标签。
